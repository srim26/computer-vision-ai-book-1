# Bab 4 — Machine Learning menuju Deep Learning

Praktik Compact Edition menggunakan dataset sintetis dua kelas untuk menunjukkan
alur **feature vector → train/test split → SVM → evaluasi**. Random Forest tetap
dijalankan sebagai pembanding, tetapi fokus narasi buku adalah SVM.

## Clean-run

Dari folder `bab04/`:

```bash
python run_all_bab04.py
```

Output utama:
- `output/output_bab04_result.json`
- `output/output_04_01_confusion_matrix_svm.png`

Dataset pada `dataset/` dibuat ulang oleh generator dan tidak perlu disimpan ke GitHub.
