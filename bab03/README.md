# Bab 3 — Dari Pixel Menuju Informasi Visual

Folder ini menyatukan praktik **image processing** dan **feature extraction**
yang pada repository produksi lama berada di dua bab berbeda.

## Clean-run

Dari folder `bab03/`:

```bash
python run_all_bab03.py
```

Urutan yang dijalankan:
1. `00_generate_synthetic_scene.py`
2. `01_image_processing.py`
3. `02_extract_features.py`
4. `03_generate_feature_output.py`

Aset `jeruk.jpg` adalah foto milik penulis. Citra `img_03_01_practice_scene.png`
dibuat secara deterministik oleh generator sintetis.
